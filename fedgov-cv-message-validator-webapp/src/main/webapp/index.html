Connected Vehicles Message Validator

This application provides validation for SAE J2735-2024 messages encoded as ASN.1 Unaligned PER (UPER) bytes.

A message for validation can be provided as a binary file via file browse or file drag and drop, or by pasting the message bytes encoded as HEX or String.

Please note that decoding UPER encoded messages per specification requires the decoder to know the ASN.1 definition of the message. Since messages that arrive at the SDC/SDW warehouses do not explicitly provide that information, the warehouses attempt to derive the information from a message itself. If a message is formatted correctly, this results in proper and unambiguous detection of the message type and the subsequent successful decoding of the message. However, for messages that contain errors, it’s impossible for the warehouses and this validator to produce an accurate error report. The recommended validation procedure below is designed to mitigate the problem.

Recommended message validation steps:

  1. Select desired ASN.1 Specification Version. (Currently only supported version is J2735-2024 but messages should be backward compatible to previous versions)
  2. Specify Data Encoding if message bytes are provided as an encoded string. (Currently only supported encoding is HEX) but binary file can be imported using file browse or drag and drop.
  3. Select the message type MessageFrame or any other provided Message Type (MAP, SPaT, TIM, BSM, PSM, SDSM, SSM, SRM)
  4. Provide the binary message by browsing for a bin file, or using file drag and drop, or pasting the message bytes encoded as HEX String.
  5. Click Validate.
  6. If the message is validated correctly (message type and validation results are green)
    1. Verify that the message type matches the intended type of the provided message. If those match, no other actions are necessary and the message is ready for deposit to the warehouses.
    2. If the message type does not match, please report them to CAV support services at CAVSupportServices@dot.gov providing the message file or string, expected message type, and detected message type from the validator. This message can’t be deposited until the problem is resolved.
  7. If the message fails validation, the message type will be marked as “Unknown” in red. Decoding failures may result from unsupported message types or incomplete messages.

The application is compatible with most modern browsers including Internet Explorer, Firefox, and Chrome. If you experience any problems using the application, please report them to CAV support services at CAVSupportServices@dot.gov
